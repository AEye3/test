# Minutescape (GitHub Pages)

This repo now contains a very simple browser version of **Minutescape** that runs as a static site.

## Run locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish with GitHub Pages

1. Push this branch to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your default branch and `/ (root)` folder.
5. Save. GitHub Pages will serve `index.html` as the game.
